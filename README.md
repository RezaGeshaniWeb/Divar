# پروژه دیوار (Divar-API)

کلون پلتفرم آگهی‌های دیوار با **Node.js**، **Express**، **MongoDB (Mongoose)** و قالب‌های **EJS**.

این پروژه امکان ورود با کد یک‌بارمصرف (OTP)، مدیریت دسته‌بندی‌ها، گزینه‌های داینامیک هر دسته، و ثبت/نمایش/حذف آگهی را فراهم می‌کند.

## نصب و راه‌اندازی

### ۱. کلون یا دانلود پروژه

```bash
cd Divar-API
```

### ۲. نصب وابستگی‌ها

```bash
npm install
```

### ۳. تنظیم فایل محیطی

فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید:

```bash
copy .env.example .env
```

سپس مقادیر داخل `.env` را مطابق محیط خود تنظیم کنید.

### ۴. اطمینان از اجرای MongoDB

MongoDB باید در حال اجرا باشد و آدرس آن با `MONGODB_URL` داخل `.env` یکی باشد.

---

## متغیرهای محیطی

| متغیر | توضیح | مثال |
|--------|--------|------|
| `PORT` | پورت سرور | `3000` |
| `NODE_ENV` | محیط اجرا (`development` یا `production`) | `development` |
| `MONGODB_URL` | آدرس اتصال به MongoDB | `mongodb://127.0.0.1:27017/divar` |
| `JWT_SECRET_KEY` | کلید امضای JWT | یک رشته امن و تصادفی |
| `COOKIE_SECRET_KEY` | کلید امضای کوکی | یک رشته امن و تصادفی |
| `MAP_IR_URL` | آدرس API معکوس Map.ir | `https://map.ir/reverse/no` |
| `MAP_API_KEY` | کلید API مربوط به Map.ir | کلید دریافتی از پنل Map.ir |

> اگر کلید Map.ir معتبر نباشد، ثبت آگهی همچنان انجام می‌شود؛ فقط فیلدهای آدرس خالی می‌مانند.

## راهنمای استفاده

### ۱. ورود به حساب کاربری

1. به آدرس `/auth/login` بروید.
2. شماره موبایل را وارد کنید و روی **دریافت کد تایید** بزنید.
3. چون ارسال SMS در این پروژه پیاده‌سازی نشده، کد OTP در پاسخ API و روی صفحه ورود نمایش داده می‌شود.
4. کد را تایید کنید تا کوکی `access_token` تنظیم شود و وارد پنل شوید.

نمونه با API:

```http
POST /auth/send-otp
Content-Type: application/json

{
  "mobile": "09120000000"
}
```

```http
POST /auth/check-otp
Content-Type: application/json

{
  "mobile": "09120000000",
  "code": "12345"
}
```

### ۲. ایجاد دسته‌بندی

از طریق Swagger یا ابزارهایی مثل Postman:

```http
POST /category
Content-Type: application/json

{
  "name": "املاک",
  "icon": "home",
  "slug": "real-estate"
}
```

برای زیردسته، فیلد `parent` را با `id` دسته والد ارسال کنید.

### ۳. ایجاد گزینه برای دسته

```http
POST /option
Content-Type: application/json

{
  "title": "متراژ",
  "key": "meterage",
  "type": "number",
  "guide": "متراژ به متر مربع",
  "required": true,
  "category": "CATEGORY_ID"
}
```

مقادیر مجاز `type`: `number` | `string` | `boolean` | `array`

اگر `type` برابر `array` باشد، می‌توانید `enum` را به‌صورت آرایه یا رشته جدا‌شده با ویرگول بفرستید.

### ۴. ثبت آگهی

1. وارد حساب شوید.
2. به `/post/create` بروید.
3. دسته مورد نظر را انتخاب کنید.
4. آدرس را روی نقشه مشخص کنید، تصاویر و اطلاعات را وارد کنید و آگهی را منتشر کنید.
5. آگهی‌های خود را در `/post/my` ببینید یا حذف کنید.

### ۵. مشاهده آگهی‌ها

- لیست همه آگهی‌ها: `/`
- فیلتر بر اساس اسلاگ دسته: `/?category=real-estate`
- جستجو در عنوان و توضیحات: `/?search=آپارتمان`
- جزئیات یک آگهی: `/post/:id`

## توضیح Endpointها

### صفحات وب (EJS)

| متد | مسیر | نیاز به ورود | توضیح |
|-----|------|--------------|--------|
| `GET` | `/` | خیر | صفحه اصلی و لیست آگهی‌ها |
| `GET` | `/panel` | خیر* | داشبورد پنل |
| `GET` | `/auth/login` | خیر | صفحه ورود |
| `GET` | `/swagger` | خیر | مستندات Swagger |
| `GET` | `/post/create` | بله | صفحه انتخاب دسته و ثبت آگهی |
| `GET` | `/post/my` | بله | لیست آگهی‌های کاربر |
| `GET` | `/post/:id` | خیر | صفحه جزئیات آگهی |

\* مسیر `/panel` در کد فعلی گارد ندارد؛ مسیرهای مدیریت آگهی نیاز به ورود دارند.

---

### ماژول Auth — پایه: `/auth`

| متد | مسیر | نیاز به ورود | Body | توضیح |
|-----|------|--------------|------|--------|
| `POST` | `/auth/send-otp` | خیر | `{ mobile }` | ارسال/ذخیره کد OTP (کد در پاسخ برمی‌گردد) |
| `POST` | `/auth/check-otp` | خیر | `{ mobile, code }` | بررسی OTP و تنظیم کوکی JWT |
| `GET` | `/auth/logout` | بله | — | خروج و پاک‌کردن کوکی |

**نمونه پاسخ موفق `send-otp`:**

```json
{
  "message": "کد تایید با موفقیت ارسال شد",
  "code": "48321"
}
```

**نمونه پاسخ موفق `check-otp`:**

```json
{
  "message": "ورود با موفقیت انجام شد"
}
```

---

### ماژول User — پایه: `/user`

| متد | مسیر | نیاز به ورود | توضیح |
|-----|------|--------------|--------|
| `GET` | `/user/whoami` | بله | برگرداندن اطلاعات کاربر لاگین‌شده |

**نمونه پاسخ:**

```json
{
  "_id": "...",
  "mobile": "09120000000",
  "fullName": null,
  "createdAt": "..."
}
```

---

### ماژول Category — پایه: `/category`

| متد | مسیر | نیاز به ورود | Body / Params | توضیح |
|-----|------|--------------|---------------|--------|
| `POST` | `/category` | خیر | `{ name, icon, slug?, parent? }` | ایجاد دسته‌بندی |
| `GET` | `/category` | خیر | — | دریافت درخت دسته‌ها (ریشه + فرزندان) |
| `DELETE` | `/category/:id` | خیر | `id` در مسیر | حذف دسته و گزینه‌های مرتبط |

**نمونه ایجاد دسته:**

```json
{
  "name": "خودرو",
  "icon": "car",
  "slug": "car",
  "parent": null
}
```

---

### ماژول Option — پایه: `/option`

| متد | مسیر | نیاز به ورود | Body / Params | توضیح |
|-----|------|--------------|---------------|--------|
| `POST` | `/option` | خیر | `{ title, key, type, category, guide?, enum?, required? }` | ایجاد گزینه |
| `GET` | `/option` | خیر | — | لیست همه گزینه‌ها |
| `GET` | `/option/:id` | خیر | `id` | دریافت یک گزینه |
| `GET` | `/option/by-category/:categoryId` | خیر | `categoryId` | گزینه‌های یک دسته با شناسه |
| `GET` | `/option/by-category-slug/:slug` | خیر | `slug` | گزینه‌های یک دسته با اسلاگ |
| `PUT` | `/option/:id` | خیر | فیلدهای قابل‌به‌روزرسانی | ویرایش گزینه |
| `DELETE` | `/option/:id` | خیر | `id` | حذف گزینه |

---

### ماژول Post — پایه: `/post`

| متد | مسیر | نیاز به ورود | ورودی | توضیح |
|-----|------|--------------|--------|--------|
| `GET` | `/post/create` | بله | Query: `slug?` | صفحه ثبت آگهی / انتخاب دسته |
| `POST` | `/post/create` | بله | `multipart/form-data` | ایجاد آگهی جدید |
| `GET` | `/post/my` | بله | — | آگهی‌های کاربر جاری |
| `GET` | `/post/:id` | خیر | `id` | جزئیات آگهی |
| `DELETE` | `/post/delete/:id` | بله | `id` (+ `_method=delete` در فرم) | حذف آگهی |

**فیلدهای مهم فرم ایجاد آگهی (`multipart/form-data`):**

| فیلد | نوع | توضیح |
|------|-----|--------|
| `title_post` | متن | عنوان آگهی |
| `description` | متن | توضیحات |
| `amount` | عدد | قیمت |
| `category` | ObjectId | شناسه دسته |
| `lat` | عدد | عرض جغرافیایی |
| `lng` | عدد | طول جغرافیایی |
| `images` | فایل(ها) | حداکثر ۱۰ تصویر (png/jpg/jpeg/webp، حداکثر ۳ مگابایت) |
| سایر کلیدها | متن | گزینه‌های داینامیک دسته (بر اساس `key`) |

**حذف از طریق فرم HTML با `method-override`:**

```html
<form action="/post/delete/POST_ID?_method=delete" method="post">
  <button type="submit">حذف</button>
</form>
```

**فیلتر لیست آگهی‌ها در صفحه اصلی:**

| Query | مثال | توضیح |
|-------|------|--------|
| `category` | `/?category=car` | فیلتر بر اساس اسلاگ دسته (شامل زیردسته‌ها) |
| `search` | `/?search=پراید` | جستجو در عنوان و محتوای آگهی |

## احراز هویت

- روش ورود: OTP (کد ۵ رقمی، اعتبار ۲ دقیقه)
- پس از تایید OTP، یک JWT داخل کوکی `httpOnly` با نام `access_token` ذخیره می‌شود
- مسیرهای محافظت‌شده با میدلور `Authorization` بررسی می‌شوند
- در درخواست‌های مرورگر، در صورت نبود توکن معتبر، کاربر به `/auth/login` هدایت می‌شود
- در درخواست‌های API، پاسخ JSON خطای فارسی برمی‌گردد

[http://localhost:3000/swagger](http://localhost:3000/swagger)

> برای تست مسیرهای نیازمند ورود، ابتدا با `check-otp` لاگین کنید تا کوکی در مرورگر تنظیم شود.

## نکات مهم

1. **ارسال پیامک واقعی وجود ندارد**؛ کد OTP در پاسخ `send-otp` برگردانده می‌شود تا توسعه و تست ممکن باشد.
2. کتابخانه‌های `method-override` و `multer` برای حذف آگهی از فرم و آپلود تصویر ضروری هستند و در وابستگی‌های پروژه قرار دارند.
3. تصاویر در مسیر `public/upload` ذخیره می‌شوند.
4. تاریخ‌ها در قالب‌ها با `jalali-moment` به‌صورت شمسی نمایش داده می‌شوند.
5. برای عملکرد کامل نقشه و آدرس، یک `MAP_API_KEY` معتبر از [Map.ir](https://map.ir/) تهیه کنید.
6. فایل `.env` را هرگز در مخزن گیت قرار ندهید.
